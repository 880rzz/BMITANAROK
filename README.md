# BMITANAROK

Bécsi Magyar Iskola – tanári és foglalkozásvezetői profilok.

Production: https://tanarok.magyariskola.at/

Kapcsolódó források:
- https://programvalaszto.magyariskola.at/
- https://www.magyariskola.at/

A profilok egységes szerkezete:
1. szakmai háttér és legfontosabb tapasztalatok;
2. kiemelt szakmai területek;
3. pedagógiai szemlélet.

A nyilvános profilokba csak szakmailag releváns adatok kerülnek. Magánlakcím, születési dátum és más, a bemutatkozáshoz nem szükséges önéletrajzi adat nem kerül publikálásra.
